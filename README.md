# 采集工作台 + 虚构报表门户

从零实现的本地演示系统：**报表门户**（选组织/账期/口径，异步生成结果）、
**后台自动执行器**、**网页工作台**（人工接管与恢复）。全部使用虚构账号，
不登录任何真实平台。仅依赖 Python 3 标准库，无需安装任何包。

## 启动

```bash
./run.sh            # 或: python3 app/server.py  (PORT 环境变量可改端口，默认 8321)
```

打开 http://127.0.0.1:8321 ，用虚构账号登录工作台：

| 工作台账号 | 密码 | 角色 |
|---|---|---|
| `alice` | `alice123` | 分析师 |
| `bob` | `bob123` | 分析师 |

门户侧另有机器人账号 `bot-01`（由后台执行器自动登录，不对外）。

## 架构

```
app/
├── portal.py    # 虚构报表门户：账号/会话(会过期)/页面/异步生成/文件/通知/幂等
├── core.py      # 工作台核心：任务、驱动锁(栅栏令牌)、执行器状态机、审计、对账、持久化
├── server.py    # HTTP API + SSE 实时推送 + 静态资源（调度线程周期推进）
└── static/      # 网页工作台（原生 JS，无构建）
data/state.json  # 运行时持久化（重启恢复，会话除外）
```

### 关键设计决策

- **保存页面状态还是重放操作？** 两者分工：门户侧的**绑定页面**是唯一事实来源
  （相当于远程浏览器），工作台侧保留**操作日志**用于审计与幂等键复用。
  恢复（交回/重启/会话过期）时重新读取门户真实状态继续，不盲目重放、不沿用缓存。
- **页面绑定任务**：只有通过任务打开的页面才计入进度。人直接上门户浏览产生的
  **游离页面**（哪怕是另一个组织）永远不会被当作任务进度——窗口关了再开也一样。
- **驱动锁 + 栅栏令牌**：同一时刻只有一个驱动者（后台或某人）。每次控制权转移
  令牌 +1，持旧令牌的操作一律 409 拒绝——接管期间后台不会继续点击，
  被强制接管的人也不会误操作。
- **幂等键**：提交生成使用 `task:条件指纹:attempt` 作为幂等键。动作已生效但
  回执丢失时，用同一键重试，门户去重返回原单，不会重复建单。
- **结果归属**：每个结果记录条件指纹 + 产生者（后台/某人）。有效性以**页面实时
  条件**为判定基准；交回时任务条件同步为页面条件，旧条件结果标记「已被取代」，
  不再沿用。任务完成只认与当前条件指纹一致的有效结果。
- **通知丢失 → 对账**：下载完成通知可能丢失（可注入），工作台每 3 秒对账门户侧
  属于本任务的文件，补记未归档结果（只认绑定页面产生的 job）。
- **会话过期**：门户会话 120 秒过期（也可一键注入过期）。后台执行器自动重新登录
  并从断点继续；人工操作收到 401 后点「重新登录门户」恢复。全程留有审计。

### 内置的“会卡住”场景（用于演示接管）

- **控件变化**：组织=华南事业部 且 口径=法定口径 时，门户新增必填控件
  「补充说明」，执行器不认识 → 卡住转人工。
- **门户侧卡死**：账期=2026-09 且 口径=含税口径 时，生成停在 66% 直至超时，
  需人工「催办」或调整条件。

## 演示脚本（需求 → 操作）

1. **正常流程**：新建任务（华北/2026-10/管理口径）→ 看后台自动选条件、提交、
   等待、下载归档，结果归属 🤖。
2. **接管与交回**：新建（华南/2026-10/法定口径）→ 执行器卡在新增必填控件 →
   alice 点「接管」（后台立即暂停）→ 填「补充说明」→ 提交 → 「交回后台」→
   执行器按页面当前条件继续直至完成。条件对照表与时间线展示交接前后归属。
3. **交回不沿用旧结果**：对已完成任务接管，把账期改成另一期再交回 →
   旧结果被标记「已被取代」，后台按新条件重新生成。
4. **回执丢失**：故障注入打开「提交回执丢失」→ 新建任务 → 时间线可见
   「提交回执丢失 → 幂等恢复」，门户透视中只有一个生成单。
5. **通知丢失**：打开「下载通知丢失」→ 接管期间提交 → 门户透视中通知显示
   「✗ 已丢失」，但结果被对账自动找回（审计可见）。
6. **两人争抢**：alice 接管某任务；bob 登录后点「请求接管」被拒（409）→
   bob「强制接管」→ alice 的后续操作被拒（STALE_TOKEN）。
7. **会话过期**：点「使门户会话过期」→ 后台自动重登继续（审计可见）；
   人工操作则提示后点「重新登录门户」恢复。
8. **游离页面**：门户透视里「以我的身份打开游离页面」，把它切到别的组织 →
   任务进度与结果完全不受影响。
9. **窗口关闭**：关掉浏览器再开，任务与接管状态都在（状态持久化）；
   服务重启后任务从断点继续，门户会话需重新登录。
